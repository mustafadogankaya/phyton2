Sample Module Repository
========================

This simple project is an example repo for Python projects with a React frontend component.

`Learn more <http://www.kennethreitz.org/essays/repository-structure-and-python>`_.

Frontend Component
------------------

A React-based frontend application has been added to this repository. The frontend provides:

- User input functionality
- Data display with timestamps
- Turkish language interface
- Responsive design

To run the frontend:

.. code-block:: bash

    cd frontend
    npm install
    npm start

The frontend will be available at ``http://localhost:3000``.

For detailed frontend documentation, see ``frontend/README.md``.
